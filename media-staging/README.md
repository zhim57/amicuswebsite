# Private media handoff
Place Leonardo/Mureka candidates and original masters here, grouped by manifest ID. This folder is outside the publicly served assets directory. Its contents other than this README are ignored by Git.

See [asset manifest](../docs/asset-manifest.md) and [structured register](../docs/asset-manifest.json). No paid media has been ordered or generated. The corporate sharing card was created locally from the existing brand; Leonardo illustrations remain pending.

Keep account receipts and rights evidence private. Do not place secrets, activation codes or unreviewed legacy photos into generation services. Only selected, cleared and optimized web copies should be copied to `public/assets/media/`; no runtime template references pending media.
